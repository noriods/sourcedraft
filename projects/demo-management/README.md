# demo-management

Demo project. Sources:
- `openstax-ch2-managerial-decision-making.pdf`: Chapter 2 of "Principles of Management", OpenStax (Rice University), CC BY 4.0, https://openstax.org/books/principles-management. Pages 35-64 of the original PDF, unchanged.
- `publisher-slides-standin.pptx`: a stand-in for a publisher slide deck, generated from that chapter for this demo (also CC BY 4.0, derived from OpenStax).
- `objectives.md`: example course objectives written for the demo.
